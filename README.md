# ebook-learning

Vault Obsidian ghi chú khi đọc ebook chuyên ngành.

- `Templates/Ebook.md`: template cho 1 cuốn sách (Obsidian: Ctrl+P → "Insert template").
- `Books/`: mỗi cuốn một note.
- File PDF/epub KHÔNG đưa vào repo (xem `.gitignore`), để ngoài vault.

## Đồng bộ giữa các máy
Plugin **Obsidian Git**: auto pull khi mở vault, auto commit + push mỗi 5–10 phút.
